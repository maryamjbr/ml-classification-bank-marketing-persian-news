## `bank_marketing.csv`

This file is the UCI Bank Marketing `bank-additional-full.csv` dataset used by
the bank-classification notebook. See the repository `NOTICE.md` for attribution
and licensing information.

## `persian_news.csv`

This file is intentionally **not redistributed** in the public repository because
the original source and redistribution license of the course-provided dataset
could not be verified.

To run `notebooks/persian_news_naive_bayes.ipynb`, place your authorized local
copy here with the filename:

```text
persian_news.csv
```

Expected schema:

| Column | Description |
| --- | --- |
| `Text` | Persian news headline/text |
| `Topic` | One of `Economy`, `Sport`, `Tech` |

The coursework copy contained 61,843 rows.
